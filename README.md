# TG BOT - задачи, таблетки, погода

Telegram-бот на Python, aiogram, SQLite и APScheduler.
Разработан с помощью сил чатаГПТ и ручек Мамкиного программиста

## Возможности

- Добавление таблеток
- Ежедневные напоминания выпить таблетку, в том числе за 5 минут
- Редактирование расписания
- Работа с задачами
- Возможность каждое утро получать информацию о погоде, задачах и времени до их дедлайна
- угабуга

## Запуск

### 1. Создать виртуальное окружение

```bash
python -m venv .venv
```

### 2. Активировать

macOS / Linux:

```bash
source .venv/bin/activate
```

Windows:

```powershell
.venv\Scripts\activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```
