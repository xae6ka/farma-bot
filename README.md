# Telegram Bot — Напоминание о таблетках

Telegram-бот на Python, aiogram, SQLite и APScheduler.

## Возможности

- Добавление таблеток
- Несколько приёмов в день
- Ежедневные напоминания
- Напоминание за 5 минут
- Кнопка `✅ Выпил`
- Кнопка `⏰ Через 10 минут`
- Повторное напоминание каждые 10 минут до подтверждения
- Редактирование расписания
- Удаление таблеток
- Отдельный список таблеток для каждого Telegram-пользователя
- Сохранение данных в SQLite
- Восстановление расписаний после перезапуска бота

## Запуск

### 1. Создать виртуальное окружение

```bash
python -m venv .venv
```

### 2. Активировать

macOS / Linux:

```bash
source .venv/bin/activate
```

Windows:

```powershell
.venv\Scripts\activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Создать `.env`

Скопируй `.env.example` в `.env` и вставь токен Telegram-бота:

```env
BOT_TOKEN=твой_токен
```

### 5. Запустить

```bash
python bot.py
```

После первого запуска рядом с `bot.py` автоматически появится `pills.db`.

## Важно

Бот отправляет напоминания только пока Python-процесс запущен и компьютер подключён к интернету.

Время расписания использует часовой пояс компьютера, на котором запущен бот.
